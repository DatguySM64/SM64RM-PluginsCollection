# CrystalFix
Allows using vertex colors with materials that have the "crystal" effect.
## Runtime Libraries
Place these in your `Data/Libs` folder within your SM64RM installation.
- **Harmony** ([Download](https://github.com/pardeike/Harmony/releases))
## Build Dependencies
Place these next to the plugin's folder for compiling.
- "`Shared Libs`" ([Download](https://gitlab.com/Pilzinsel64/sm64-rom-manager/-/tree/1.14/dev/Shared%20Libs?ref_type=heads))
- "`SM64Lib`" ([Download](https://gitlab.com/Pilzinsel64/sm64-rom-manager/-/tree/1.14/dev/SM64Lib?ref_type=heads))
